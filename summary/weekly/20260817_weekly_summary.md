# Azure 주간 업데이트 요약 - 2026년 08월 17일

## 🔒 네트워킹 및 보안

지난주 Azure에서는 네트워킹과 보안 부문에서 실질적 성능 개선과 기능 혁신이 이뤄졌습니다. Azure Firewall의 IDPS 성능이 두 배 가까이 향상되며 TLS 검사에 따른 처리량이 대폭 증대되어, 대규모 엔터프라이즈 환경에서 보안과 속도 모두 만족할 수 있게 되었습니다. Azure Front Door도 복잡한 규칙 세트를 더욱 안전하고 예측 가능한 방식으로 관리할 수 있도록 배치 규칙 업데이트 기능이 정식 지원되어 운영 편의성이 크게 높아졌습니다. 또한, Mutual TLS 미리 보기 출시로 클라이언트 인증, 데이터 보호의 수준이 한층 강화되었으며, IoT 및 금융 등 민감한 환경에서도 보안 접점이 확대되었습니다. 이처럼 Azure 네트워크 및 보안 서비스의 주요 업데이트들은 관리 자동화, 배포 신뢰성, 그리고 다양한 업무 시나리오에서의 보안 강화 측면에서 새로운 도약을 제공하고 있습니다.

### [Azure Firewall의 2.2배 IDPS 성능 최적화 정식 지원](https://azure.microsoft.com/updates?id=569256)
Azure Firewall Premium에서 TLS 검사 및 IDPS 적용 시, 최대 22Gbps 처리량과 TCP 연결당 최대 600Mbps를 제공하며, 실제 업무에 적합한 네트워크 보안을 실현합니다.

### [Azure Front Door의 배치 규칙 업데이트 정식 지원](https://azure.microsoft.com/updates?id=569246)
여러 규칙을 한 번에 배치 관리할 수 있어, 배포의 예측성과 안전성이 증가하고, 복잡한 환경에서도 안정적인 운영이 가능합니다.

### [Azure Front Door Mutual TLS 미리 보기 출시](https://azure.microsoft.com/updates?id=569251)
클라이언트 인증 기능인 Mutual TLS로 데이터 보호와 인증을 강화하여 비즈니스 및 IoT 등 다양한 환경에서 민감 정보의 보안을 보장합니다.

## 📊 컴퓨트·스토리지·관리

컴퓨트, 스토리지, 관리 분야에서는 AKS, App Service, Disk Storage 등 핵심 인프라 서비스의 효율성과 자동화 능력이 한층 강화되었습니다. 공유 프리미엄 SSD v2 및 Ultra 디스크 Live Resize 기능이 정식 지원되면서 무중단 확장과 비용 최적화가 촉진되고, AKS 관리 평면 메트릭 수집 기능 도입으로 클러스터 운영의 가시성이 크게 향상되었습니다. App Service에서는 AI 에이전트를 위한 Markdown 변환 미리 보기 기능이 출시되어, 앱 정보를 더 쉽게 활용할 수 있게 되었으며, 개발자·관리자의 편의성이 대폭 상승했습니다. 이러한 변화는 신속한 확장·유지보수와 동시에 안전성을 확보할 수 있는 현대적인 클라우드 운영 기반을 제공하며, 실질적인 비용 절감과 업무 효율화에 기여합니다.

### [공유 프리미엄 SSD v2 및 Ultra 데이터 디스크 Live Resize 정식 지원](https://azure.microsoft.com/updates?id=569281)
중단 없이 디스크 용량을 확장할 수 있어, 애플리케이션 안정성과 비용 효율화가 동시에 보장됩니다.

### [AKS 관리 평면 메트릭 수집 기능 정식 지원](https://azure.microsoft.com/updates?id=568830)
관리 평면의 다양한 메트릭을 수집하여 플랫폼 팀이 클러스터 상태를 쉽고 명확하게 감시할 수 있습니다.

### [Azure App Service 에이전트용 Markdown 미리 보기 출시](https://azure.microsoft.com/updates?id=568979)
HTML을 자동으로 Markdown으로 변환하여 AI 에이전트 등에서 앱 정보를 더 편리하게 소비할 수 있게 되었습니다.

## 🛢️ 데이터베이스·하이브리드·멀티클라우드

데이터베이스와 하이브리드, 멀티클라우드 환경에서는 운영 신뢰성과 예측성 향상에 중점을 둔 업데이트가 이뤄졌습니다. Azure Database for PostgreSQL에서 사전 업그레이드 검증 기능이 정식 지원되면서, 업그레이드 전 호환성 문제 및 장애 위험을 미리 확인·대응할 수 있어 유연하고 안전한 마이그레이션이 실현됩니다. Microsoft Sentinel SAP 컨테이너형 데이터 커넥터 에이전트는 지원 종료가 결정되어, Agentless 커넥터로의 전환이 반드시 필요해졌습니다. 반복적인 업그레이드 검증과 환경별 맞춤 지원이 강화되어 클라우드 데이터 관리에 대한 신뢰와 안정성이 대폭 상승했습니다.

### [PostgreSQL Flexible Server 사전 업그레이드 검증 기능 정식 지원](https://azure.microsoft.com/updates?id=568419)
업그레이드 전 호환성 확인이 가능하여 장애 위험을 줄이고, 생산 환경에서 안정적인 마이그레이션이 가능합니다.

### [Microsoft Sentinel SAP 컨테이너형 데이터 커넥터 에이전트 지원 종료](https://azure.microsoft.com/updates?id=568457)
2026년 9월 14일부터 해당 에이전트는 완전히 비활성화되며, SAP 로그 수집은 Agentless 커넥터를 통해 이어집니다.

### [업그레이드 사전 검증 및 환경별 반복 지원](https://azure.microsoft.com/updates?id=568419)
검증 절차의 반복적 수행이 가능하여 확실한 준비를 통해 업그레이드 성공률을 높일 수 있습니다.

Azure Databricks Runtime 10.4 LTS의 지원 종료 예고로 인해 반드시 마이그레이션 해 장애를 사전에 방지해야 하며, Microsoft Fabric에서도 아이템 복구 기능이 기본적으로 활성화되어 데이터 관리의 안전성과 표준화가 강조됩니다. 특히 마이그레이션 가이드와 검증 절차 제공으로 클러스터 운영 안전성을 확보하고, 복구 정책의 보편화로 데이터 보호 및 장애 대처 능력이 높아지는 등 데이터 기반 업무환경의 안정성과 관리 편의성이 크게 향상되었습니다.

### [Azure Databricks Runtime 10.4 LTS 지원 종료 예고](https://azure.microsoft.com/updates?id=569353)
2026년 11월 1일 이후 해당 버전 사용이 불가하므로 반드시 신규 버전으로 마이그레이션 해야 합니다.

### [Microsoft Fabric 아이템 복구 기본 활성화](https://azure.microsoft.com/updates?id=569140)
설정이 없는 테넌트에서 3일 복구 윈도우가 기본으로 적용되어 데이터 보호가 자동으로 강화됩니다.

### [버전 지원 종료 이전 마이그레이션 가이드 및 검증](https://azure.microsoft.com/updates?id=569353)
Databricks 마이그레이션 및 클러스터 검증을 통해 장애 예방과 데이터 보호를 실현할 수 있습니다.
